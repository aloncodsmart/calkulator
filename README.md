# מתמטיקה חכמה

אפליקציית ווב (מותאמת לנייד) שמלמדת **איך לפתור** במתמטיקה, ולא רק נותנת תשובות. היא מיועדת לתלמידי חטיבת ביניים ותיכון בישראל (כיתות ז–יב, 3/4/5 יח"ל) ובנויה לפי תוכנית הלימודים של משרד החינוך ולפי מבנה בחינות הבגרות.

בכניסה הראשונה בוחרים כיתה ורמה, ומאותו רגע המשפטים, המושגים, הנוסחאות והתרגילים מותאמים לרמה שנבחרה.

## מה יש באפליקציה

| לשונית | מה עושים בה |
|---|---|
| **פותר** | **פתרון:** פתרון צעד אחר צעד של משוואות, אי-שוויונות, מערכות, נגזרות, חקירת פונקציה, משיק, אינטגרלים ופישוט ביטויים, עם מקלדת מתמטית ותצוגה מקדימה. כל פתרון נפתח בסולם רמזים (כיוון → משפט או כלל מתאים → הצעד הבא), ורק אחריו מגיע הפתרון המלא. **איזה משפט?** מתארים את הנתונים ואת מה שצריך להוכיח, ומקבלים משפטים מתאימים ומה צריך לבדוק לפני שמצטטים אותם. **בדיקה:** כותבים את הפתרון שלכם שורה אחר שורה, והאפליקציה מסמנת את השורה הראשונה שבה נפלה טעות ומסבירה למה, בלי לפתור במקומכם. **כלים:** סדרות, משולש ישר זווית, משפט הסינוסים והקוסינוסים (כולל המקרה הדו-משמעי) ושתי נקודות במישור |
| **משפטים** | 118 משפטים. לכל משפט יש ניסוח, ניסוח סימבולי, תנאים לשימוש, הניסוח לעמודת הנימוק, שרטוט, דוגמה פתורה בטבלת "טענה \| נימוק", טעויות נפוצות, משפט הפוך ותגיות. כל משפט מסומן *מותר לצטט*, *בדף הנוסחאות* או *צריך להוכיח*. באותה לשונית נמצא גם **דף הנוסחאות** לפי יח"ל |
| **מושגים** | מילון של 324 מושגים עם אינדקס א–ת. לכל מושג יש הסבר פשוט, הגדרה מדויקת, שרטוט, דוגמה ומושגים קשורים |
| **תרגול** | מחולל תרגילים ב-26 נושאים ובשלוש רמות קושי, עם בדיקת תשובה, רמזים ופתרון מלא. בנוסף יש כרטיסיות חזרה (משפטים, מושגים, נוסחאות ושמורים) עם חזרה מרווחת |
| **התקדמות** | נושאים חזקים לעומת נושאים לחיזוק, רצף ימים, המלצות "מה לעשות עכשיו" ושליטה בכרטיסיות |

בכותרת העליונה יש **חיפוש חכם** (לפי מילה, לפי נושא או לפי צורת השרטוט), מעבר בין מצב בהיר לכהה, והגדרות.

### פתרון עם Claude (לא חובה)

הפותר המובנה עובד בלי אינטרנט. כדי לפתור שאלות מילוליות, הוכחות בגאומטריה ושאלות מצולמות, ולבדוק פתרון בכתב יד, מוסיפים בהגדרות מפתח API של Claude (מ-[console.anthropic.com](https://console.anthropic.com)).

- המפתח נשמר רק בדפדפן, לא נכלל בקובץ הגיבוי, ונשלח רק ל-API של Anthropic.
- המודל מקבל את כל מאגר המשפטים ומחויב לצטט רק ממנו. נימוק שמפנה למזהה שאינו במאגר מוסר, ומה שאינו ברשימה מסומן "צריך להוכיח".
- התשובות מגיעות כ-JSON מובנה (structured outputs), ומוצגות עם אותו סולם רמזים ואותה טבלת "טענה | נימוק".
- ברירת המחדל היא Claude Opus 5.5, ואפשר לעבור ל-Claude Sonnet 5.5.

## על התוכן – חשוב לקרוא

לא צורף קובץ רשמי של משרד החינוך, ולכן הניסוחים במאגר הם הניסוחים המקובלים בתוכנית הלימודים ובספרי הלימוד. כשיש ספק אם משפט מופיע ברשימת המשפטים שמותר לצטט, הדבר כתוב במפורש בשדה `note` ומוצג בדף המשפט. משפטים שלפי ידיעתנו אינם ברשימה מסומנים **צריך להוכיח**, וההוכחה הקצרה מופיעה בדוגמה. גם נוסחאות שכנראה אינן מודפסות בדף הנוסחאות מסומנות (`extra`). לפני בחינה כדאי להשוות לרשימה העדכנית של הפיקוח על המתמטיקה.

## הרצה

```bash
npm install
npm run dev        # שרת פיתוח
npm test           # בדיקות (vitest)
npm run build      # בדיקת טיפוסים ובנייה לתיקיית dist
npm run preview    # הרצת הגרסה הבנויה
```

הגרסה הבנויה היא אתר סטטי (עם ניתוב hash ו-`base: './'`), ואפשר להעלות אותה לכל אחסון סטטי, למשל GitHub Pages.

## עריכת התוכן

כל התוכן נמצא בקובצי JSON, ואין צורך לגעת בקוד:

- **משפט** (`src/data/theorems/*.json`): `id`, `name`, `statement`, `formal` (LaTeX), `citation` (מה כותבים בעמודת הנימוק), `conditions`, `useWhen`, `diagram`, `example` (שלבי טענה–נימוק; `ref` מפנה למשפט), `mistakes`, `converse`, `status` (`official` / `formula-sheet` / `needs-proof`), `topic`, `grades`, `units`, `keywords`, `givens`/`goals` (לכלי "איזה משפט?"), `related`, `note`.
- **מושג** (`src/data/concepts/*.json`): `term`, `aliases`, `simple`, `formal`, `diagram`, `example`, `related`.
- **טקסט עם מתמטיקה:** עברית רגילה, ומתמטיקה בין `$...$` (בתוך שורה) או `$$...$$` (שורה נפרדת). בתוך LaTeX כותבים עברית רק בתוך `\text{...}`.
- **שרטוט** (`src/data/diagrams/*.json`): נקודות בקואורדינטות, או נקודות שנבנות מנקודות אחרות (`mid`, `foot`, `inter`, `on`, `tan`, `incenter` ועוד), ורשימת אלמנטים (`seg`, `poly`, `circle`, `arc`, `angle`, `right`, `tick`, `par`, `fn`, `axes` ועוד). הטיפוסים המלאים מוגדרים ב-`src/types.ts`.

הבדיקות (`npm test`) מוודאות שכל ביטוי LaTeX במאגר עובר רינדור ב-KaTeX, שכל ההפניות בין משפטים, מושגים ושרטוטים תקינות, שכל ציטוט בדוגמאות תואם לניסוח של המשפט שאליו הוא מפנה, ושכל פותר ומחולל נותן תשובה נכונה (ההצבה חזרה מתקיימת).

---

**Smart Math** is a mobile-first Hebrew (RTL) web app for Israeli middle- and high-school students that teaches problem solving step by step: a local step-by-step solver with a hint ladder, a "which theorem fits?" finder, a line-by-line solution checker, guided calculators, a theorem database with Bagrut citation status, a concept dictionary, a formula sheet, an exercise generator, spaced-repetition flashcards and progress tracking. It is built with React, TypeScript, Tailwind CSS and KaTeX, keeps all content in JSON and all progress in `localStorage`, and can optionally use Claude (user-supplied API key) for photo questions and geometry proofs.
