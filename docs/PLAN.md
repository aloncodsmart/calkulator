# מתמטיקה חכמה – תוכנית עבודה

## 1. מבנה מסכים

ניווט תחתון קבוע: **פותר | משפטים | מושגים | תרגול | התקדמות**. בכותרת העליונה יש חיפוש חכם, מצב כהה והגדרות.

| מסך | תת-מסכים | מה יש בו |
|---|---|---|
| כניסה ראשונה | בחירת כיתה, בחירת רמה | כיתות ז–יב. בכיתות ז–ט בוחרים רמה (בסיסית/רגילה/מוגברת), ובכיתות י–יב בוחרים 3, 4 או 5 יח"ל |
| **פותר** | פתרון שאלה · איזה משפט מתאים? · בדיקת פתרון · כלים מודרכים | הקלדה עם מקלדת מתמטית או צילום (AI). סולם רמזים 1→2→3 ורק אחריו פתרון מלא. בגאומטריה הפתרון כתוב בטבלת "טענה \| נימוק" עם ציטוט מדויק של המשפט |
| **משפטים** | רשימה · דף משפט · דף נוסחאות | סינון לפי נושא, לפי רמה ולפי "מותר לצטט" או "צריך להוכיח". בכל משפט: ניסוח, תנאים, שרטוט, דוגמה פתורה, טעויות נפוצות, משפט הפוך ותגיות |
| **מושגים** | מילון · דף מושג | אינדקס א–ת וסינון לפי נושא. בכל מושג: הגדרה פשוטה, הגדרה פורמלית, שרטוט ומושגים קשורים |
| **תרגול** | מחולל תרגילים · כרטיסיות שינון | תרגילים חדשים לפי נושא וקושי, עם בדיקה, רמזים ופתרון. כרטיסיות עם חזרה מרווחת (SM-2) |
| **התקדמות** | – | חוזק לכל נושא, נושאים שדורשים חיזוק, רצף ימים והמלצות |
| חיפוש | – | לפי מילת מפתח, לפי נושא או לפי סוג שרטוט ("חיפוש לפי שרטוט") |
| הגדרות | – | פרופיל, ערכת צבע, מפתח API (אופציונלי), ייצוא/איפוס נתונים, מקור התוכן |

## 2. מבנה נתונים (קובצי JSON ב-`src/data`)

- `topics.json`: נושאים (מזהה, שם, אייקון, צבע, כיתות, יח"ל).
- `theorems.json`: משפטים.
  ```jsonc
  {
    "id": "isosceles-base-angles",
    "name": "זוויות הבסיס במשולש שווה שוקיים",
    "statement": "במשולש שווה שוקיים זוויות הבסיס שוות זו לזו.",
    "formal": "AB=AC \\Rightarrow \\angle B=\\angle C",
    "citation": "במשולש שווה שוקיים, מול צלעות שוות זוויות שוות",
    "conditions": ["..."],
    "useWhen": "...",
    "diagram": "isosceles",
    "example": { "problem": "...", "steps": [{ "claim": "...", "reason": "..." }], "answer": "..." },
    "mistakes": ["..."],
    "converse": { "id": "isosceles-converse" },
    "status": "official | formula-sheet | needs-proof",
    "topic": "isosceles", "grades": [8], "units": [4, 5],
    "keywords": ["..."], "givens": ["isosceles"], "related": ["isosceles-triangle"]
  }
  ```
- `concepts.json`: מושגים (מונח, כינויים, הגדרה פשוטה, הגדרה פורמלית, שרטוט, דוגמה, מושגים קשורים, נושא, כיתות, יח"ל).
- `formulas.json`: דף הנוסחאות, מחולק לפרקים, וכל נוסחה מתויגת ברמת יח"ל.
- `diagrams.json`: שרטוטים בשפת תיאור מובנית (נקודות, קטעים, מעגלים, זוויות, סימוני שוויון, גרפים), ורכיב React הופך אותם ל-SVG. נקודה יכולה להיות קואורדינטה, אמצע קטע, נקודה על מעגל, עקב אנך או חיתוך ישרים, כך שקל להוסיף שרטוט חדש.

התקדמות, כרטיסיות והגדרות נשמרות מקומית ב-`localStorage`.

## 3. רשימת נושאים

**גאומטריה:** זוויות וישרים מקבילים · משולשים · חפיפה · משולש שווה שוקיים · אי-שוויונות במשולש · קטעי אמצעים · נקודות מפגש ומקומות גאומטריים · משולש ישר זווית ופיתגורס · מרובעים (מקבילית, מלבן, מעוין, ריבוע, טרפז, דלתון) · דמיון ותאלס · מעגל · משיקים · שטחים ונפחים.

**אלגברה ומספרים:** ביטויים אלגבריים · חזקות ושורשים · לוגריתמים · משוואות ואי-שוויונות · מערכות משוואות.

**פונקציות וחשבון:** פונקציות (קווית, ריבועית, רציונלית, שורש, מעריכית, לוגריתמית, טריגונומטרית) · חשבון דיפרנציאלי · חשבון אינטגרלי.

**נושאים נוספים:** טריגונומטריה (במישור ובמרחב) · גאומטריה אנליטית · סדרות · הסתברות · סטטיסטיקה והתפלגות נורמלית · גדילה ודעיכה · וקטורים · מספרים מרוכבים.

## 4. מנוע הפתרון

- **מקומי (עובד בלי אינטרנט):** מפענח ביטויים, ופותרים מפורטים צעד אחר צעד למשוואות ממעלה ראשונה ושנייה, משוואות עם שברים, משוואות דו-ריבועיות, מערכות משוואות, אי-שוויונות, נגזרות, נקודות קיצון ואינטגרלים. לכל אלה יש סולם רמזים. בבדיקת פתרון באלגברה המערכת משווה את קבוצת הפתרונות בין כל שתי שורות עוקבות ומאתרת את השורה הראשונה שבה נפלה טעות. כלים מודרכים: סדרות, משולש ישר זווית, משפט הסינוסים והקוסינוסים, ושתי נקודות במישור.
- **AI (אופציונלי, עם מפתח API של Claude):** פתרון מצילום, שאלות גאומטריה חופשיות ובדיקת פתרון מצילום. המודל מקבל את מאגר המשפטים ומחויב לצטט רק ממנו. כל טענה שאינה במאגר מסומנת "צריך להוכיח".

## 5. בדיקות

- כל ביטויי ה-LaTeX במשפטים, במושגים ובנוסחאות עוברים רינדור KaTeX בלי שגיאות.
- כל ההפניות בין קבצים תקינות: משפט הפוך, מושגים קשורים, שרטוטים ונקודות בשרטוט.
- כל פותר וכל מחולל נבדק מתמטית: הצבת הפתרון חזרה במשוואה.
